# Kalender: ukenummer ved siden av

Fasit: `Kalender.dc.html` (mobil og web).

- **Månedsvisning:** egen smal kolonne til venstre (24 px) med ISO-ukenummer for hver rad. Kolonneoverskrift «U». IBM Plex Mono 10, `mut`. Trykk på tallet åpner uken i Uke-visning.
- **Minikalender** (sidepanelet på web og nedtrekket på mobil): samme kolonne (22 px), Plex Mono 9.5, `mut`, «U» i overskriften. Trykk → Uke-visning for den uken.
- Uke-/3 dager-/Dag-visning viser allerede «U43» øverst til venstre, beholdes.
- ISO 8601 (mandag første dag, uke 1 = uken med 4. januar).
