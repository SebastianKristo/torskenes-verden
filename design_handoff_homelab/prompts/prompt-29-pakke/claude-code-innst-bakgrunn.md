# Innstillinger: bakgrunnsvelger i toppen

Fasit: `Mobil Papir App.dc.html` → Innstillinger.

- Vis den samme pillen **«<bakgrunn> ▾»** (f.eks. «Planeter ▾») i toppen av Innstillinger, rett til venstre for profilbildet. Den er lik den på Hjem.
- Stil: høyde 34, pille, `rgba(27,26,23,.55)` + blur 8, hvit tekst Manrope 12.5/600.
- Trykk åpner samme bakgrunnsmeny som på Hjem (Nåværende, Oslo, Vær nå, Planeter …, eget bilde). Valget gjelder hele appen.
- Rekkefølge i toppraden: «‹ Hjem» · (luft) · «Planeter ▾» · profilbilde.
