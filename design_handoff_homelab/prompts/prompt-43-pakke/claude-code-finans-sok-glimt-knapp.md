# Finans (mobil): rød Glimt-knapp med Glimt-orben i Søk og Liste

Ønske 2026-10-21: «her og i søk i finans på mobil legg til rød og glimt ikonet» (vedlegg `uploads/Screenshot 2026-10-21 at 11.22.50.png`: Finans → Søk, «✦ Glimt»)
Fasit: `Mobil Papir App.dc.html` → Finans → **Søk** (`fs.togAi`) og Finans → **Liste** (søkefeltet).

- **Søk:** knappen til høyre i søkefeltet: **[Glimt-orben 20 px på hvit rund brikke] Glimt**. På: rød `lab` fylt, hvit tekst. Av: rød kant, rød tekst, 12 % rød bakgrunn. Ingen «✦».
- **Liste:** «✦ AI» (mono-tekst) erstattes av samme røde pille **[orb] Glimt** (34 pt høy). Trykk åpner Finans → Søk med Glimt på og det som står i feltet.
- Orben: konisk fargering (#b23a2a → #e8794a → #7a5ad6 …) med kremfarget innside og rød firetakket stjerne, roterer sakte, raskere mens Glimt svarer. Brikken bak (hvit 92 %) gjør at den synes på rødt.
- iOS/Android: samme. Trykkflate minst 44 pt.
