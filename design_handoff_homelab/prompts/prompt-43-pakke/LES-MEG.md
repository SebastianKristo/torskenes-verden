# Prompt 43 – pakke til Claude Code

Les `prompt-43.md` først (alle ønsker ordrett med dato og hva som ble gjort). Hver `claude-code-*.md` er én oppgave. `design/` er fasit (åpne `.dc.html` i nettleseren, `support.js` må ligge ved siden av). `vedlegg/` er skjermbildene ønskene viser til.

## Rekkefølge
1. **Feil først**
   - `claude-code-vaer-web-klikk-fiks.md` · Vær på web kan ikke klikkes
   - `claude-code-kalender-mac-fryser.md` · Mac-appen og widgeten fryser
   - `claude-code-wiggle-ios-virker-ikke.md` · wiggle på iOS (Subscription OS er fasit)
   - `claude-code-fold-delt-hjem-fiks.md` · Hjem på Fold er ikke delt
   - `claude-code-gsc-ingen-statistikk.md` · Search Console viser ingenting
   - `claude-code-kalender-mac-menylinje-fiks.md` · menylinje-menyen reagerer ikke
2. **Media (ny modul)**
   - `claude-code-media-arr.md` · Sonarr, Radarr, qBittorrent, Prowlarr, Glimt, magnet, legg til indekser
   - `claude-code-integrasjoner-media.md` · Integrasjoner med oppsett steg for steg (web + mobil)
   - `claude-code-media-widgets.md` + `claude-code-widget-galleri.md` · widgets og Widgets-side
3. **Kalender**
   - `claude-code-kalender-oppdater-i-appen.md` · oppdatering fra appen (Mac/Android)
   - `claude-code-kalender-oppsett-stor-skjerm.md` · velg oppsett i onboarding (iPad/Fold)
   - `claude-code-kalender-web-lukk-tema.md` · × til høyre, «Tema: følger»
   - `claude-code-kalender-web-liste-bredde.md` · Liste i full bredde, Glimt «Dagen din» i sidepanelet
   - `claude-code-kalender-web-knapper.md` · rød «+ Ny hendelse», Glimt-orb på «Skriv time»
4. **Chat og Glimt**
   - `claude-code-chat-claude-import.md` · importer minne og samtaler fra Claude
   - `claude-code-sok-ai-svarboble.md` · dra ned → Chat med samme svar
   - `claude-code-chat-send-knapp-tom.md` · send-knappen tom/fylt, ikke utenfor kortet
5. **Finans, Gjøremål, Domener**
   - `claude-code-finans-saldokort.md` · nytt saldokort (4b i Papir)
   - `claude-code-finans-liste-maned-topp.md` · månedstopp i Liste
   - `claude-code-finans-sok-glimt-knapp.md` · rød Glimt-knapp med orb
   - `claude-code-gjoremal-faner-rekkefolge.md` · «+ Ny liste» sist, endre rekkefølge
   - `claude-code-domener-glimt-i-kortet.md` · Glimt-raden i domenekortet (orb, ikke figur)
6. **Stor skjerm**
   - `claude-code-stor-skjerm-alle-sider.md` · iPad og Fold for alle sider
