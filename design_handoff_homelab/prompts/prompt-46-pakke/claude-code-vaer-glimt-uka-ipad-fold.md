# Vær på iPad og Fold: kortet «Glimt · Ukas vær»

Skjermbilde: `uploads/Screenshot 2026-10-23 at 13.51.44.png`
Fasit: `Vaer.dc.html`, brett-oppsettet (`FOLD`, to kolonner, brukt av appen på iPad og Fold åpen). Kortet lå før nederst under alt annet. Nå ligger det **nederst i venstre kolonne** (under Nå, Time for time og 10 dager), i tomrommet ved siden av detaljkortene (Solnedgang, UV, Føles som …) i høyre kolonne (`glO` = 50 på brett). Mobil bruker fortsatt kortrekkefølgen fra «Rediger kort».

## Innhold (samme som på mobil)
- Etikett «GLIMT · UKAS VÆR» med Glimt-ringen.
- Velger Sky / Ugle / Spire (personlighet, lagres i `vaer_glimt_p`).
- Figur + «[navn] · [stil]» + oppsummering av uka.
- Tre bokser: TEMP (endring mot forrige uke), NEDBØR (mm, forrige), SOL (timer, forrige).
- Rader: Beste dag ute, Paraply, Klær.

## Krav
- Vises på iPad (stående og liggende) og Fold åpen. Fold lukket/mobil: uendret plassering (styres av kortrekkefølgen).
- Respekter «Rediger kort»: skjult kort skjules også her.
- Samme data og samme Glimt-tekst som mobilkortet (ingen ny generering per layout).
