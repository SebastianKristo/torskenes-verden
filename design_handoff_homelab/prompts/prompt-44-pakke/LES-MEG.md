# Prompt 44 – pakke til Claude Code

Les `prompt-44.md` først (alle ønsker ordrett med dato). Hver `claude-code-*.md` er én oppgave. `design/` er fasit (åpne `.dc.html` i nettleseren, `support.js` ved siden av). `vedlegg/` er skjermbildene.

## Rekkefølge
1. Feil i appen: oppdatering hopper mellom skjermer (web), Media «ikke innlogget» på mobil, interaktivt søk 504, Kalender iPad/innlogging/hastighet.
2. Gjøremål: infoside, deloppgaver, synk i Innstillinger.
3. Kalender: hold/trykk for ny hendelse, rediger, klokkeslett i Glimt, adresse, deltakere, Media-kalender, I dag-ikon.
4. Media: søk, plakater, Kommer snart-liste, banner, last ned på nytt/slett, servervalg, frem/tilbake, Avspilling (Plex/Jellyfin), Tab-forslag.
5. Innstillinger: lys/mørk på web, overfør eier, logg inn som familiemedlem, tidligere versjoner.
6. Mer, Studie, Glimt-pynt.
