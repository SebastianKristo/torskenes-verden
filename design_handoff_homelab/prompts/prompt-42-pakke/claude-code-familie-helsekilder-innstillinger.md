# Familie: Apple Health / Health Connect flyttes til Innstillinger

Ønske 2026-10-20: «legg dette i innstillinger ikke i helse» (vedlegg `uploads/Screenshot 2026-10-20 at 21.43.08.png`: kortene «Apple Health · Koblet til via appen · iPhone» og «Health Connect · Koblet til via appen · Android» øverst i Familie → Helse).
Fasit: `Familie.dc.html` (kortene fjernet fra Helse) + `Mobil Papir App.dc.html` → Innstillinger → gruppen **HELSE (FAMILIE)**.

- Fjern de to kildekortene fra toppen av Familie → **Helse**. Fanen starter rett med personene og helsedataene deres.
- Innstillinger → **Helse (Familie)**:
  - **Apple Health**: «Koblet til via appen · iPhone» · «✓ Koblet» / «Koble til». Trykk: be om HealthKit-tilgang eller vis hvor den endres.
  - **Health Connect**: «Koblet til via appen · Android» · samme logikk med Health Connect-tillatelser.
  - **Hva deles med familien**: skritt, søvn, puls og aktivitet, valgt per person.
- På web: samme gruppe under Familie-innstillinger, med status per enhet.
