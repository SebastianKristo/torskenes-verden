# Media: topplinje som i Nyheter

Fasit: `Media.dc.html` (mobil-topp) og `Nyhetsleser.dc.html` (mal).

- Venstre: pilleknapp **«‹ Tilbake»** (36px høy, 1px kant, gjennomsiktig, 13px/600) – samme som Nyhetsleser. Erstatter runde ‹-knappen.
- Ved siden av: kicker i mono rød **«MEDIA · FILMER OG SERIER»** (10.5px, letter-spacing .12em, ellipsis) og tittel **«Media»** (Newsreader 34px) rett under, på samme rad som knappene.
- Høyre: ✦ Glimt og innstillinger, runde 40px med kant (som ⋯/⚙ i Nyheter).
- Den separate «Media»-tittelen under raden fjernes.
- Tilbake-sveip fungerer som før (se `claude-code-ios-tilbake-sveip.md`).
