# Prompt 36: pakke til Claude Code

Start med `prompt-36.md` (alle ønsker ordrett, med dato). Hvert ønske peker på én `claude-code-*.md` med fasit i en `.dc.html`-fil.

## Instrukser (gjør i denne rekkefølgen)
1. `claude-code-matplan-delt.md`: matplanen er alltid felles for alle brukere
2. `claude-code-backup-nettverksdisk-fiks.md` (+ `claude-code-backup.md`): SMB-undermapper, og backup «tatt», men tom mappe
3. `claude-code-system-oppdatering-nordlys.md`: endringsnotater mangler, tidligere versjoner, Sherlock-Glimt og snekker-Glimt
4. `claude-code-nordlys-oppstartsside.md`: «Starter opp»-side med Glimt
5. `claude-code-glimt-en-indikator.md`: én Glimt-visning (spørsmål vs. handling) + spørsmål med dato er ikke avtale
6. `claude-code-glimt-brief.md`: fast bredde + ring + sveip bort + hint + Now Brief i Mer
7. `claude-code-web-dashboard-rediger.md`: wiggle-redigering på web (rutenett, kolonner, snapp, størrelse) + i profilmenyen
8. `claude-code-vaer-web.md`: ny PC-layout, været for alle steder, uskarpe kort i himmelfarge
9. `claude-code-hjem-temperatur-trykk.md`: trykk på temperaturen åpner Vær, hold inne åpner Yr
10. `claude-code-bakgrunn-uten-tekst.md`: fjern kredit-teksten over bakgrunnen
11. `claude-code-domener-hurtig.md` + `claude-code-domener-ai-oppsummering.md`: statistikk med en gang + Glimt-knapp ved domene-baren
12. `claude-code-konto-profilbilde.md`: profilbilde i Konto
13. `claude-code-innstillinger-ikoner.md`: ikon på alle rader i Innstillinger
14. `claude-code-innst-web-skjul-scrollbar.md`: skjul scroll-streken på web

## Design (fasit, åpnes direkte i nettleseren)
`design/`: alle `.dc.html` + `support.js`, `glimt-figurer.js`, `i18n.js`, `domener-kart.js`, `assets/`.
Nye i denne prompten: `Nordlys Starter.dc.html`, `Dashboard Rediger Web.dc.html`, `Vaer Web.dc.html`.

## Vedlegg
`vedlegg/`: skjermbilder brukeren la ved, med samme navn som i prompt-36.md, men som .jpg (komprimert for å holde pakken under 30 MB). Skjermopptaket (22-11-25) er utelatt: det viser at Brief-siden blir bredere mens Glimt guider, og at den røde ringen rundt Vær sitter skjevt. Se `claude-code-glimt-brief.md`.
