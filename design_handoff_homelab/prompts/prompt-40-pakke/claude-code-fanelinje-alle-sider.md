# Fanelinja (mobil): alt fra Mer kan legges til

Ønske 2026-10-20: «jeg vil kunne velge hvilkesom helst fra mer menyen i navbarem»
Fasit: `Mobil Papir App.dc.html` → `HNAV_ALL`, `ne.adds`, fane-`go`.

- «LEGG TIL» i «Rediger fanelinjen» viser **alle** sidene som finnes i Mer, ikke bare et utvalg: Hjem, Finans, Mat, Sporing, Domener, Media, Abonnement, Familie, Gjøremål, Chat, Søk, Vær, Nyheter, **Kalender, Bursdager, Now Brief, Nyhetsleser, Bibel (bare for brukere med modulen), Aksjer, Nordlys, Innstillinger**.
- Bygg lista fra **samme kilde** som Mer-menyen (én liste med nøkkel, navn, ikon og rute), så nye sider automatisk kan legges i fanelinja.
- Sider som er ark/overlegg (Now Brief, Nyhetsleser) åpnes som ark når fanen trykkes; vanlige sider navigeres til.
- Maks 5 faner pluss «Mer» (som før). Valgte faner forsvinner fra «Legg til» og vises fortsatt i Mer.
- Hver fane har samme ikon som i Mer-menyen i alle tre stilene (Tekst / Bare ikoner / Ikoner + navn på valgt).
