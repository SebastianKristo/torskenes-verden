# Media (web): X-knapp i stedet for innstillinger-ikon

- I headeren på Media (alle faner): fjern innstillinger-ikonet (slider-ikon) helt til høyre.
- Erstatt med en rund lukkeknapp (48×48, 1px #E3DED3 kant, bakgrunn #FCFBF7, X-ikon 18px, strek 2px).
- Knappen gjør det samme som «‹ Tilbake»: lukker Media og går til dashboardet. aria-label="Lukk Media".
- Innstillinger for Media hører hjemme i appens Innstillinger-side, ikke i Media-headeren. Flytt eventuelle innstillinger dit hvis de ikke allerede ligger der.
