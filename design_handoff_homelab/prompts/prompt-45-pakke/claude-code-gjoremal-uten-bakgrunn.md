# Gjøremål: fullskjerm uten bakgrunnsbilde

Fasit: `Mobil Papir App.dc.html` (side `huske`).

- Gjøremål viser **ikke** bakgrunnsbildet (himmel/Oslo/planet) i toppen.
- Toppen bruker Papir-bakgrunnen (`--bg`) med mørk tekst (`--ink`), som Nordlys-siden: «‹ Hjem», «To-do for hele familien», «Gjøremål», S-knapp med lys kant og skygge.
- Innholdet overlapper ikke toppen (ingen negativ marg). Hele siden er én flate fra topp til bunn.
- Gjelder telefon, Fold og iPad.
