# Alle innstillinger samles i Innstillinger-menyen

Fasit: `Innstillinger Web.dc.html`.
- Fjern egne innstillingssider/tannhjul inne i moduler (Media på web først, deretter alle faner) på web og mobil.
- Innstillinger får én seksjon per modul: Media (servere, Sonarr/Radarr/qBit/Prowlarr, Plex/Jellyfin), Gjøremål, Kalender, Ruter, Vær, Finans, Studie, Glimt/AI osv.
- Snarvei: modulens ⋯-meny kan ha «Innstillinger for Media» som åpner Innstillinger → Media direkte (ikke egen side).
- Gjøremål: «Synk med Homey/hjemmeassistent» og synkstatus fjernes fra Gjøremål-visningen og flyttes til Innstillinger → Gjøremål (se `claude-code-gjoremal-synk-i-innstillinger.md`).
