# Mer-menyen: slett seksjonstittel og velg de fire store boksene

Fasit: `Mer Ny.dc.html`.

## 1. Slett/skjul seksjonstittel
- Tittelen under søket («Hverdag og familie») og andre seksjonstitler kan fjernes i wiggle-redigering.
- I wiggle: rød (−)-knapp ved tittelen. Trykk → tittelen skjules (kortene blir stående). Kan legges tilbake via «+ Legg til tittel».
- Tittelen kan også gis nytt navn ved trykk på teksten i wiggle.

## 2. Velg innhold i de fire store boksene
- I wiggle får hver av de fire store boksene et lite «Bytt»-merke (⇄) øverst til høyre.
- Trykk → bunnark «Velg boks» med alle moduler (Kalender, Gjøremål, Bursdager, Familie, Finans, Vær, Ruter, Media, Matplan …) med ikon og forhåndsvisning. Valgt modul har hake.
- Kan også dras: dra en modul fra verktøylisten opp på en stor boks for å bytte.
- Lagres per bruker (også når admin redigerer et familiemedlems oppsett).
