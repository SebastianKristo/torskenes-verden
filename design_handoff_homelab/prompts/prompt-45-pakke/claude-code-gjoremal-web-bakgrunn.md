# Gjøremål (web): fyll skjermen og match bakgrunnen

Fasit: `Huskeliste Web Design.dc.html`.
- Fjern border/ramme og avrundet «kort» rundt hele Gjøremål-visningen.
- Visningen fyller hele innholdsflaten (100 % bredde og høyde under topplinjen), samme bakgrunn som resten av web-appen (Papir-bakgrunn).
- Kolonner/paneler skilles med tynne skillelinjer, ikke kort med skygge.
