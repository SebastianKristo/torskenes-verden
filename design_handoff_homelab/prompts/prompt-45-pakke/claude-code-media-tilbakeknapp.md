# Media: samme tilbakeknapp som resten av systemet

- Alle undersider i Media (serie/film-detalj, Sonarr/Radarr/qBit/Prowlarr, interaktivt søk, kommer snart) skal bruke systemets standard tilbakeknapp:
  runde 40 px glass-knapp med chevron ‹ (samme komponent som Kalender, Gjøremål og Innstillinger), plassert øverst til venstre i felles topplinje.
- Fjern Media-spesifikke varianter (tekstknapp «‹ Tilbake», pil-ikoner med annen tykkelse, annen farge).
- Web: samme knapp + nettleserens tilbake/frem fungerer fortsatt.
