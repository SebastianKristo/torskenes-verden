# Media: mer farge (mobil og web)

- Hver tjeneste får sin farge brukt konsekvent (ikon, aktiv fane, statusprikker, fremdriftslinjer):
  Sonarr `#35c5f4`, Radarr `#ffc230`, qBittorrent `#3d7dd6`, Prowlarr `#e66001`, Plex `#e5a00d`, Jellyfin `#aa5cc3`.
- Postere: bakgrunnstoning hentet fra posterens dominante farge i detaljvisningen (svak gradient bak hero).
- Statuspiller i farger: Lastes ned (blå), Venter (gul), Ferdig (grønn), Mangler (rød), Uovervåket (grå).
- Seedere grønne / peers røde beholdes.
- Behold Papir-bakgrunnen; farge brukes som aksent, ikke heldekkende flater.
