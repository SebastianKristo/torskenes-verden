# Boliger (mobil): fjern «Fra e-post», flytt Tilgang til innstillinger

Ønske 2026-10-24: «fjern fra epost knappen og tilgang knappen kan ligge kun i nettversjon eller i innstliger på mobil.»
Design: `Boliger.dc.html`. Gjelder iOS og Android (telefon). Web (`Boliger Web.dc.html`) er uendret.

1. **Handlinger:** fjern flisen «Fra e-post». Igjen står tre like fliser: Skann, Last opp, Ny utgift. E-postimport finnes fortsatt på web, og e-poster som videresendes, havner fortsatt i «Til gjennomgang».
2. **Faner:** bare «Oversikt» og «Utgifter · N». Fjern fanen «Tilgang».
3. **Tilgang i innstillinger:** i bolig-innstillingene (arket som åpnes når du redigerer boligen) står raden «Delt med N», med avatarer og undertekst «Tilgang · hvem som kan se og laste opp ›». Den åpner Tilgang-siden (Hvem har tilgang, Del boligen, Om boligen) med «‹ Oversikt» øverst.
4. Raden «Delt med N» fjernes fra Oversikt.
