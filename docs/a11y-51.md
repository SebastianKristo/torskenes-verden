# Tilgjengelighet (prompt 51, A11Y51)

Hva er gjort: Hovedsidene (innlogging, Hjem, Gjøremål, Kalender, Familie, Familiekalender, Media, Innstillinger, FinansHub, Planlegging og søkepaletten) har nå 0 brudd i `npm run a11y`, både i lys og mørk modus og på 1440 og 390 px. Før var det 1155 brudd.

- **Kontrast:** Dempede tekstfarger i lyst papir (`--ink3`, `--muted`, `--mut2`, `--k-mut`, `--g-ink2`, `--w30-mut`, `--pp-mut` m.fl.) er gjort mørkere, slik at de holder minst 4,5:1. Mørk modus har egne, lysere verdier. Helfargede dashbordkort beholder hvit tekst også i mørk modus. Lyse kort i mørk modus blander etikettfargen mot lys tekst. Ruter-linjemerker får en mørkere bakgrunn i samme fargetone når hvit tekst ellers ville kommet under 4,5:1.
- **Berøringsflater:** Små tekstlenker og -knapper (nyhetslinjen, snarveier, «Endre», «Se alle», «Logg inn med passord») har fått usynlig polstring i høyden. Små ikonknapper i kalenderen er gjort litt bredere. Alle er nå minst 24 × 24 px (WCAG 2.2), og ingenting har flyttet seg.
- **Fokus:** Felt som skrur av omrisset, viser nå en fokusring ved tastaturfokus. Søkefelt som ligger inni en ramme, viser ringen rundt hele rammen.
- **Bakgrunnsmenyen** (Oslo ▾) er skjult for skjermlesere og tabulatortasten når den er lukket (`visibility:hidden`).

Kommandoer:

```
npm run a11y                       # sjekker, feiler bare på nye brudd (grunnlinjen er 0)
npm run a11y -- --strict           # feiler på alle brudd
npm run test:visual                # skjermbildetester
UI51_PORT=4632 npm run a11y        # egen port hvis 4621 er i bruk
```

Du trenger ikke gjøre noe selv. Nettleseren henter de nye stilene når service workeren oppdateres (os-v38, finanshub-v56).
